# 0.2.14 — 上传模板至共享 Gallery

模板详情页新增「上传至共享 Gallery」，将所选版本的内置或个人模板快照保存到中心资源库。需要 Gallery 0.32.0+ 并已连接中心服务；未安装或未配置时显示原因。

- 只通过已认证的人工 Web 操作上传，服务端读取准确源版本，拒绝浏览器伪造模板内容。
- 保留成员 Skill / MCP 开关、任务、门控、验收、归档与循环配置，不上传执行实例状态。
- 同一版本重复上传复用副本，不覆盖 Gallery 编辑；新版本创建新资源。
- 中心仍使用独立用户身份，其他用户不可修改或删除上传者的资源。
- Gallery 创建页字段名称同步模板库，既有 JSON 格式保持兼容。

本次按用户授权更新 main，未合入 dev 的 Super Agent 功能，未发布 npm 包。
