# 0.2.13 — Gallery 按需资源接入

成员打开原有 Gallery Skill / MCP 开关后，通过 Gallery 0.30.0+ 的按需模式搜索资源、加载所需 Skill、查询并调用所需 MCP 工具，避免向每个成员预注入完整目录及工具定义。界面和模板字段不变。

- 新建、冷恢复统一安装模式，生命周期清理沿用原机制。
- 启用访问时明确检查 Gallery 能力，缺失或旧版本提示升级；不静默回退全量模式。
- 管理员工具白名单继续生效，缺少入口授权时提示具体工具；原生 MCP 调用仍受原始策略检查。
- 普通聊天的直接 Skill / MCP 调用保持原方式，中心 stdio 许可保持原约束。
- 增加成员安装回归和可选跨仓库真实 HTTP MCP 联调测试；详见 docs/gallery-discovery.md。
