# Agent 资源创建方案

当前 Agent 在 Gallery 中仍使用通用资源编辑器，没有专用格式。本文件定义下一版创建向导的字段和保存边界，确认后再实现。

## 资源结构

Agent 是一份配置及其可选附属文件，建议目录如下：

```text
my-agent/
├── AGENT.md           # 必需：角色、任务目标、行为指引
├── config.json         # 可选：模型、工具、执行参数
├── references/         # 可选：参考资料
└── assets/             # 可选：模板与素材
```

`AGENT.md` 作为 Gallery 可移植格式，不宣称是 DSH 原生 Agent 预设文件。只有接入 DSH Agent 运行时之后，才转换为该版本所需的预设配置。模型凭据和其他密钥不放入资源文件。

## 创建向导

1. **身份**：英文标识、显示名称、简介、头像或图标（可选）。列表以显示名称为主；英文标识用于导出目录。
2. **职责**：主要任务、何时启用、处理边界、系统指引。即时预览 `AGENT.md`。
3. **能力**：选择可用 Skill、工具或 MCP，设置模型与执行参数。未接入的能力显示为待配置，不提供失效的可选项。支持添加参考资料和模板。
4. **检查保存**：目录预览、标签、权限与依赖检查，保存为一条 Agent 资源。

编辑沿用同一向导，回填原字段和文件，不重建资源 ID。Gallery 只保存配置；在会话中使用 Agent 需要明确的 DSH 运行时适配与启动入口，不能把保存资源等同于可执行 Agent。
