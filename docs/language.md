# 跟随 DSH 系统语言（0.28.0）

Gallery 不提供独立语言开关，跟随 DSH 的中英文设置。切换后，已打开的 Gallery、创建/编辑向导和提示即时更新，不需要刷新页面。

覆盖资源浏览与榜单、九种主题、主题菜单、Skill/Agent/MCP 创建与导入、Workflow 画布与成员栏、存储设置、确认对话框、悬浮通知和 `/gallery` 菜单提示。日期和数字按当前界面语言格式化，Gallery、Skill、Agent、MCP、Workflow 保持原有品牌/类型名称。

切换语言不会自动翻译、覆盖或重新生成资源名称、描述、标签、用户名、文件路径、Markdown、附件、Agent 指令或 Workflow 已填写的内容。已有草稿和保存内容保留原文，内置示例内容也保留原文。系统在新建时生成的可编辑默认内容一旦进入草稿，就随草稿保留。

实现使用 DSH 插槽注入的翻译函数读取 `dsh-gallery/language.code`，通过 React Context 更新子组件。上下文按页面隔离，不使用全局语言变量或 DOM 文本替换。对话框保持组件状态，悬浮通知虽挂在页面外仍随语言更新；Skill 菜单在请求候选项时读取宿主当前语言。

维护界面文案时：

- 组件使用 `useGalleryText()`，系统文案通过 `l("中文源文案")` 渲染。
- 英文译文集中在 `src/client/messages-en.mjs`；参数使用 `{0}`、`{1}` 等占位符，两种语言保持参数集合相同。
- `l` 只能用于界面、系统标签和反馈，不包裹用户填写的资源名称、描述或正文。
- 后端已生成的已知反馈可在显示时按模板翻译；未知服务端/第三方错误保留原始信息，不翻译其中的用户数据。
- 编辑器解析 Markdown 标题、判断路径和序列化资源时使用稳定原文，不使用翻译结果作为数据协议或解析条件。

测试覆盖语言代码、品牌名、占位符、反馈回译、字段验证标签和 Skill 菜单；浏览器验证宿主开关即时生效、打开的向导不丢草稿、资源正文不变以及九种主题的英文手机布局。
