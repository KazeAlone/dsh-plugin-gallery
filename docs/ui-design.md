# Gallery UI · 0.4.0

## 设计方向

简洁、极简、扁平，适用于 DSH 内嵌的资源管理工具。使用系统字体，避免引入外部字体、图标依赖、渐变、毛玻璃、装饰阴影和营销文案。

- 分类统一为「全部 / Skill / Agent / MCP / Workflow」单行导航，使用明确的按下状态。
- 资源以分隔线列表展示，名称为主要信息，描述、标签、文件数和日期为次要信息。
- 基础文字 14px，标题 24px，资源名称 15px；辅助信息 12–13px。手机表单输入使用 16px。
- 中性色为主，颜色只用于状态、焦点和反馈；浅色和深色独立定义语义色值。
- 控件小圆角，弹窗统一头部、可滚动内容和固定操作区。无保存动作不自动关闭编辑。
- 编辑支持取消和未保存确认；弹窗支持 Esc、Tab 循环和关闭后焦点恢复。
- 手机端分类导航换行适配，列表保留名称、描述和文件/时间信息；标签在详情中仍可查看。

## 验证

构建与打包检查、18 项既有功能测试通过。使用真实 React 组件、模拟 RPC 数据及 Chromium 验证：

- 分类、搜索、详情、文件展开与资源引用。
- 新建资源、添加文本文件、内容编辑、保存。
- 嵌套确认弹窗、Esc、焦点循环。
- 存储检查、新增资源库和切换。
- 375、667、768、1280px 布局，浅色、深色和减少动效设置。

这些浏览器检查在隔离页面完成，未覆盖完整 DSH 宿主壳层。本次没有修改资源格式、存储协议或数据库。
