# Gallery UI · 0.5.1

## 设计方向

简洁、扁平、图形优先，适用于 DSH 内嵌的资源管理工具。使用系统字体，避免引入外部字体、图标依赖、渐变、毛玻璃、装饰阴影和营销文案。

- 分类统一为「全部 / Skill / Agent / MCP / Workflow」单行导航，使用明确的按下状态。
- 资源使用响应式卡片，按类型提供文档、机器人、连接节点、流程图四种 SVG 插图。插图表示类型，不冒充真实文件预览。
- 名称为主要信息，描述一行、标签最多两个；文件数和更新时间用图标辅助表达。
- 分类与详情操作提供统一线性图标；存储与刷新使用带可访问名称和悬停提示的图标按钮。
- 基础文字 14px，标题 24px，资源名称 15px；辅助信息 12–13px。手机表单输入使用 16px。
- 中性色为主，类型封面采用轻量绿、紫、蓝、橙配色；浅色和深色分别定义颜色。类型同时由图标和名称表达，不仅依靠颜色。
- 控件小圆角，弹窗统一头部、可滚动内容和固定操作区。无保存动作不自动关闭编辑。
- 编辑支持取消和未保存确认；弹窗支持 Esc、Tab 循环和关闭后焦点恢复。
- 手机端分类使用图标加标签，资源卡片单列排列，保留名称、描述、标签和文件/时间信息。

## 验证

构建与打包检查、18 项功能测试通过。使用真实 React 组件、模拟 RPC 数据及 Chromium 验证：

- 分类、搜索、详情、文件展开与资源引用。
- 新建资源、添加文本文件、内容编辑、保存。
- 嵌套确认弹窗、Esc、焦点循环。
- 存储检查、默认库直接使用；不提供新建、切换入口或当前资源库选择框。
- 375、667、768、1280px 布局，浅色、深色和减少动效设置。

这些浏览器检查在隔离页面完成，未覆盖完整 DSH 宿主壳层。本次没有修改资源格式、存储协议或数据库。

## 品牌入口

显示名称统一为 Gallery（页面标题、侧栏、中英文 locale）。图标为应用商店风格的单色购物袋加应用网格，无外围边框，颜色继承宿主文字，SVG 可在侧栏小尺寸和页面标题中复用。SVG 画布收紧至 26 × 26，并以图案中心对齐，减少去除外框后多余的留白。侧栏图标遵循宿主传入的尺寸（展开 16px、收起 18px），使图标占位和文字起点与原生入口一致。安装包名、服务名和数据目录保持稳定，升级无需迁移。

## 分类创建

全部视图只浏览资源，不提供新建入口。选中具体分类后，在分类内容区显示「新建 Skill / Agent / MCP / Workflow」。创建类型固定，不允许在编辑表单切换；导入不同类型资源包会提示进入对应分类。各类型专用内容表单待资源模型确定后扩展。

## Skill 创建向导 · 0.5.0

Skill 分类的新建入口使用四步向导：基本信息、编写指引、附属文件、检查保存。名称与描述生成 YAML front matter，正文提供模板和基础标题预览。右侧目录树显示 SKILL.md 及实际添加的 references、scripts、assets 文件；移动端放在内容下方，可折叠。

附件支持多文件上传、拖放、新建文本文件、修改路径与内容、删除、向正文插入相对链接。保存前校验名称、必填内容、重复及不安全路径、文件数与大小、Markdown 中显式指向三个附件目录的链接。整个文件集合通过既有 uiCreate 保存为一条本地资源；保存失败保留向导内容。Skill 编辑复用四步向导，回填文件头、正文与附件，使用原 ID 和修订号更新。Gallery JSON 下载继续使用原有入口，尚未提供 ZIP 导出。

本次新增格式测试，并通过模拟 RPC 的浏览器创建与手机布局检查；未运行完整 DSH 宿主集成。

## 编辑与详情 · 0.5.1

隐藏获取引用、元数据与依赖展示及通用编辑器的高级 JSON 输入。已有数据仍保留。Skill 文件头使用 YAML 解析，保留扩展字段；解析失败阻止保存，避免覆盖原文。支持读取早期向导生成的转义分隔符。创建后重新编辑并保存的浏览器流程与 23 项测试通过。
